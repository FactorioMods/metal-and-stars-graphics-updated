# Metal and Stars graphics: Updated

Provides the original Metal and Stars graphics under the maintained dependency identity. It is an asset package for the matching gameplay mod.

Requires Factorio 2.1.24 or later. Enable the dependencies listed in the mod manager. This fork keeps the original mod’s content rather than introducing a new balance model.

Existing saves using metal-and-stars-graphics can migrate to this mod identity. Keep a backup when changing a mod set, and disable the original when selecting this fork.

Original mod: [ metal-and-stars-graphics ](https://mods.factorio.com/mod/metal-and-stars-graphics). Original author credits and applicable license notices are retained in the source package.
